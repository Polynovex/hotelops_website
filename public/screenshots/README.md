# Product screenshots

Drop PNG captures here using these exact filenames. Each replaces its
placeholder frame on the homepage automatically — no code change needed.

| File | Screen to capture |
|---|---|
| `dashboard.png` | Business dashboard, showing Occupancy / ADR / RevPAR |
| `reservations.png` | Reservations list |
| `rooms.png` | Room status board |
| `housekeeping.png` | Housekeeping manager dashboard |
| `billing.png` | A guest folio with charges |
| `reports.png` | A financial or occupancy report |

Guidance:

- **16:9**, at least 1600x900, taken on a wide browser window.
- **Use demo data.** Never publish a capture containing a real guest's name,
  phone number, email, or card detail — that is a live NDPR breach, not a
  cosmetic issue.
- Light theme reads better against the site's light background.
